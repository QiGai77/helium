# Helium · 个人 AI Agent 手机 App 设计方案

> 版本 v0.1 · 2026-11-19 · 配套文件：`helium/repos.md`（5 个借鉴仓库对比与来源）

---

## 1. 产品定位

**一句话**：Helium 是装在手机里的"人生操作系统"——一个记得你、能替你动手、在关掉 App 后仍继续干活、且在花钱/发送/删除前一定先问你的个人 agent。

- **对标**：Dots / Duet / Meta Muse（个人 agent 形态）、Claude App（对话质量）、Hark（聊天+记忆+技能+浏览器代理+定时+Home 面板+审批卡+项目空间）。
- **差异化**
  1. **Google 系视觉**：Material 3 Expressive（形状变形、弹性动效、动态取色）+ Gemini 式渐变"思考光"+ Antigravity 式"任务即工件"（每个任务有可回放的步骤、截图、产物）。
  2. **Android 原生能力**：浏览器代理之外，还能在用户授权下操作手机上的其他 App（无障碍服务），覆盖没有 API 的 App（微信、支付宝、12306 等场景）。
  3. **可解释的信任**：审批是"一张可撤销、有作用域的授权"，不是一次性弹窗；所有动作可审计。
- **目标用户（MVP）**：忙碌的知识工作者/家庭管理者，Android 优先，中英双语。

## 2. 核心功能

| 模块 | 用户看到的 | 关键规则 |
|---|---|---|
| 对话 | 主对话 + 侧边线程；流式回复；内联富卡片（网页、邮件、计划、比较、收据） | 输入胶囊里"发送↔停止"同位；停止不丢草稿；执行中可继续追加消息（排队可见） |
| 长期记忆 | "关于你"页：按领域（人、饮食、出行、工作、家…）展示，可编辑、可遗忘 | 只记用户说过的；推断项标"推断"；"忘记"=全量删除+生成"不再保存"规则 |
| 技能 / 专长 | 专长库：系统专长（订餐、订机票、购物…）+ 用户自建；每个专长=说明书+工具许可+App 卡片 | 写入/修改专长属于敏感操作，需审批 |
| 浏览器代理 | 任务卡里实时画面、步骤时间线；"接管"按钮 | 登录/验证码交还用户；域名白名单；秘密只以占位符进入 |
| 手机操作代理 | "Hands" 开关；在其他 App 上的悬浮进度条 + 紧急停止 | 仅 Android；点击含"支付/转账/提交订单/发送/删除"语义的控件强制审批 |
| 定时任务 | 自动化列表：一次 / 每日 / 每周 / cron / 地理围栏 | 后台运行结果投递到对应线程与通知；失败退避；无人值守时需要审批的步骤 → 变成 Home 上的审批卡 |
| Home 面板 | 可浏览的卡片墙：追踪（价格、航班、包裹）、日程、邮件摘要、天气、进行中任务、待审批 | 刷新最快每小时；面板只读外部数据源，不存用户手填条目 |
| 审批卡 | 购买 / 发送 / 删除 / 预订 / 写记忆或专长前弹出 | 作用域：仅一次 / 本对话 / 24 小时 / 永久；按"工具+目标"绑定；可在"权限"页逐条撤销 |
| 项目空间 | 多步骤、多天的事（旅行、搬家、求职）：独立线程 + 文件 + 待办 + 产物 | 项目有自己的专长（约定、模板）与工作区 |
| 连接账户 | Google/日历/邮件 OAuth、MCP 服务器、网站登录（保险库） | 密码/卡号只进保险库，模型只见占位符；卡号永不在 UI 明文显示 |

## 3. 信息架构

```
底部导航（M3 Navigation Bar，4 项 + 中央 FAB）
├─ Home（面板墙 + 待审批 + 进行中任务）
├─ Chat（主对话；顶部切换线程/项目）
├─ [FAB：新建任务 / 语音]
├─ Projects（项目空间列表）
└─ You（记忆、专长、自动化、连接、权限、设置）
全局层：审批 Bottom Sheet、任务实时画面（全屏）、通知中心
```

## 4. 主要屏幕（供设计稿，8 屏）

**S1 · Home（今日）**
- 顶部：问候 + 一句 agent 摘要（"今天 2 件事需要你确认"）+ 头像（点开 = 状态/活动）。
- "待你确认"横向卡片带（审批卡缩略：金额/收件人/目标站点，"批准/查看"）。
- "进行中"条：每个后台任务一行，带进度环与当前步骤文字。
- 面板墙：两列瀑布（M3 Expressive 形状：大圆角、不同形状区分类型），航班、包裹、价格追踪、日程、邮件、天气。
- 长按面板 → 刷新 / 编辑 / 移除。

**S2 · 对话（主线程）**
- 消息流：用户气泡（主色容器）、agent 无气泡长文 + 内联卡片（网页摘要、比较表、计划、收据）。
- agent 工作时：Gemini 式渐变光晕沿输入胶囊流动 + "正在：搜索 3 家酒店…"可展开为步骤列表。
- 输入胶囊：+（附件/相机/文件）、文本、麦克风、发送↔停止变形按钮；上方显示"排队中的追问"。
- 顶部：线程标题、切换线程、所属项目标签。

**S3 · 任务实时画面（浏览器 / 手机代理）**
- 上半屏：实时截图流（浏览器或手机屏），操作处高亮框；"接管"大按钮（用户亲自登录/过验证码，完成后点"继续"）。
- 下半屏：步骤时间线（每步：动作、目标、耗时、截图缩略），失败步红色并给出原因。
- 底部：暂停 / 停止 / 让它重试；产物区（下载的 PDF、截图、结构化结果）。

**S4 · 审批 Bottom Sheet**
- 标题动词化："购买 · ¥1,280" / "发送邮件给 2 人" / "删除 14 个文件"。
- 区块：为什么（关联到用户原话）、具体内容（收件人、正文预览、商品与总价、目标站点）、风险标签与原因（如"会离开白名单站点""已读过你的邮件后外发"）。
- 作用域选择：仅这一次 / 本对话 / 24 小时 / 永远（敏感+有警示时仅提供"仅一次"）。
- 主按钮"批准"（大号，Expressive 按压形变）、次按钮"修改"、文字按钮"拒绝"。

**S5 · 关于你（记忆）**
- 领域分组卡片：人、饮食、出行、购物、工作、家与健康；每条一句话 + 来源类型（你说的 / 推断）。
- 单条操作：编辑、遗忘；顶部搜索；"不再保存"的规则列表。
- 隐私说明条：记忆归用户所有，可导出、可清空。

**S6 · 专长库（技能）**
- 系统专长 / 我的专长两栏；每张卡：图标、名称、一句用途、所需权限（浏览器、手机操作、付款）。
- 详情页：说明书（Markdown 可编辑）、App/站点卡片、最近使用记录、"由 agent 学到的经验"（来自任务自评）。
- 新建专长：对话式向导（"教我怎么做一次"）。

**S7 · 自动化（定时任务）**
- 列表：名称、下次运行时间（本地时区）、频率芯片、上次结果状态点。
- 详情：提示词、频率编辑器（一次/每日/每周/cron/到达某地）、运行历史（每次结果可点开回放）、暂停/跳过下一次。
- 空状态引导："同一件事问第二次时，我会建议把它变成自动化。"

**S8 · 连接与权限**
- 连接：Google、邮箱、日历、MCP 服务器、网站登录（保险库条目只显示名称与域名）。
- 权限：已授予的授权列表（"浏览器 · booking.com · 永久""发送邮件 · alice@… · 24 小时"），逐条撤销；手机操作开关（无障碍服务状态）；全局模式：谨慎 / 标准 / 放手。
- 审计：活动日志（每次工具调用、审批、结果，可筛选导出）。

（可选第 9 屏：项目空间详情 —— 线程、文件、待办、产物、项目专长。）

### 视觉要点（Google 系）
- **Material 3 Expressive**：动态取色（Android 12+ 跟随壁纸）、形状库（圆角方/四叶/药丸区分卡片类型）、弹簧动效（按钮按压形变、FAB 展开）、强调字重的排版层级。
- **Gemini 质感**：agent"在思考/在干活"统一用蓝紫渐变流光，不用转圈；完成时收束成一个亮点。
- **Antigravity 质感**：任务=工件，每个任务都有可审阅的计划、步骤截图、产物，像"任务收件箱"。
- 字体：Google Sans Flex / Roboto Flex（中文 Noto Sans SC），注意授权。

## 5. 技术架构

### 5.1 总览
```
┌────────── Android App（Kotlin + Jetpack Compose, M3 Expressive）──────────┐
│ UI 层   Home / Chat / Task Live / Approvals / Memory / Skills / Automations │
│ 设备代理  AccessibilityService "Portal"（a11y 树 + 截图 + 手势）             │
│ 本地    Room(缓存线程/卡片) · DataStore · Keystore(设备密钥) · FCM            │
└───────────────┬──────────────── AG-UI 事件流（SSE/WebSocket）+ REST ──────────┘
                │
┌───────────────▼─────────── Helium Cloud（Python）───────────────────────────┐
│ API 网关 (FastAPI)  鉴权、多租户、AG-UI 事件推送                             │
│ Agent Runtime        agent loop + Sentinel 闸门 + 工具注册 + MCP 客户端       │
│ Task Engine          Postgres 持久任务 + 租约恢复 + 调度器(一次/cron/围栏)    │
│ Memory Service       mem0 自托管 + pgvector；Markdown 档案层（可读可改）      │
│ Browser Workers      browser-use + Playwright/CDP，每用户持久 profile，容器隔离│
│ Sandbox              每任务短命容器（gVisor/Firecracker），默认无网络          │
│ Vault                KMS 加密，占位符替换，结果脱敏                           │
│ Audit                追加写日志（每次调用/审批/结果）                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 选型与理由
- **客户端：Kotlin + Jetpack Compose（Android 先行）**。理由：M3 Expressive 的组件与动效在 Compose 里一手可用；手机操作代理必须用原生 AccessibilityService；后台/前台服务、FCM、Keystore 都是原生强项。共享逻辑（网络、模型、AG-UI 解析）放 **Kotlin Multiplatform**，v2 出 iOS 时 UI 用 SwiftUI 或 Compose Multiplatform。
  - 备选：fork OpenFuse 的 `apps/mobile`（Expo/RN）可在 2–3 周拿到可跑原型，但原生 M3 Expressive 与无障碍服务都要另写原生模块——适合做"内部 demo"，不建议作为正式栈。
  - Flutter 也能仿 M3，但手机操作与系统集成同样要原生桥接，优势不明显。
- **后端：Python 3.12 + FastAPI**。理由：browser-use、mem0、Mobilerun 都是 Python，可直接作为库嵌入。
- **协议**：客户端↔后端用 **AG-UI** 事件（OpenFuse 已验证该模式：文本增量、工具调用、状态、审批请求）；工具与连接器用 **MCP**（stdio/HTTP），每个 MCP 工具可声明风险等级（借 nanoMuse `mcp_tools.py` 的做法）。
- **存储**：PostgreSQL（线程、任务、审批、授权、审计）+ pgvector（mem0 后端）+ 对象存储（截图、PDF、产物）。
- **模型**：模型无关的 LLM 层（OpenAI 兼容 + Anthropic + Gemini）；按角色分配模型（规划用强模型、执行用快模型——Mobilerun 的 llm_profiles 思路）。

### 5.3 Agent loop（每轮）
1. 组装上下文：系统提示 + 用户档案 + 相关记忆（mem0 search，top_k）+ 活跃目标/项目 + 已加载专长。
2. 调模型 → 得到文本/工具调用。
3. 每个工具调用进入 **Sentinel.guard()**：deny 列表 → 规则 → 常驻允许/询问 → 风险×模式 → taint 检查 → 警示检查 → allow / ask / deny。
4. ask → 生成审批记录 → AG-UI 推送审批卡（前台）或 FCM + Home 卡（后台）→ 等待（超时=拒绝）。
5. 执行（保险库占位符在此刻替换）→ 结果脱敏 → 写审计 → 回填上下文。
6. 停止条件：模型调用 `finish`/无工具回复；卡死检测（同调用重复无进展）；`max_steps`。
7. 轮后：抽取记忆（mem0 add）+ 专长经验（browser-use Judge 的 gotchas）→ 写入候选，**用户可见可撤**。

## 6. 路线图

**MVP（约 10–12 周）· "会聊、会记、会查、会问"**
- Android：S1 Home（基础）、S2 对话、S4 审批、S5 记忆、S8 连接（Google）。
- 后端：agent loop + Sentinel v1（风险分级、仅一次/本对话作用域、审计）；mem0 记忆；网页搜索/抓取；Gmail/日历读 + 发送审批。
- 定时任务 v1（一次/每日/每周，结果推送 FCM）。
- 指标：7 日留存、审批通过率、任务成功率。

**v1（再 12 周）· "会动手"**
- 浏览器代理（browser-use worker + 实时画面 S3 + 接管）；保险库与 `type_secret`。
- 购买/预订流程（总价确认卡、卡片只来自保险库）。
- 专长库 S6（系统专长 + 用户自建）；Judge 经验回写。
- 自动化 S7 完整版（cron、地理围栏、运行回放）；Home 面板可刷新追踪（价格/航班/包裹）。
- 项目空间（S9）；审批作用域扩展到 24h/永久 + 权限页撤销；taint 规则。

**v2 · "多设备 + 手机操作"**
- Android "Hands"：AccessibilityService 手机操作代理（Manager/Executor），敏感控件强制审批，悬浮停止条。
- iOS 客户端（KMP 共享 + SwiftUI/CMP），无手机操作能力，其余对齐。
- 每用户隔离沙盒（Firecracker/gVisor），可选"云电脑"；MCP 市场；桌面/网页端；多设备审批路由（审批推到手边设备）。

## 7. 风险与许可证

**许可证**
- **GPL-3.0（nanoMuse）**：只借设计思想，团队需书面 clean-room 规则（不复制代码/注释/文件结构）。
- **AGPL-3.0（Khoj，未入选）**：不要引入后端，网络使用即触发开源义务。
- **MIT/Apache（OpenFuse、browser-use、Mobilerun、mem0）**：保留版权与 NOTICE；建立 SBOM 与依赖许可证扫描。
- **商标**：不使用 Muse/Gemini/Google 等商标与 logo；"Google 风格"只体现在设计语言上。Google Sans 字体有使用限制，正式包用 Roboto Flex/Noto（OFL/Apache）。
- **CopilotKit Intelligence**：OpenFuse 的线程持久化依赖该闭源服务且默认遥测，迁移时必须替换。

**产品与技术风险**
- **Prompt injection 与外泄**：网页/邮件内容只是证据不是指令；taint 规则 + 外发审批 + 域名白名单 + 结果脱敏。
- **误操作花钱/发错**：所有付款/发送/删除强制审批；不确定的外部写入不自动重试（OpenFuse 做法）；同一敏感调用重复时再次警示（nanoMuse 做法）。
- **审批疲劳**：用作用域授权与"按目标绑定"减少弹窗；高风险永不常驻授权。
- **手机操作合规**：Google Play 对 AccessibilityService 有严格政策与声明要求，可能需侧载或企业分发；iOS 系统不允许。需单独法务评估。
- **反爬与验证码**：浏览器代理遇登录/验证码交还用户接管；遵守站点条款。
- **成本**：长任务 + 视觉模型很贵 → 角色分模型、a11y 树优先、步数上限、任务预算。
- **隐私合规（中国/海外）**：个人信息保护法、数据出境；记忆与保险库加密、可导出可删除；模型供应商数据政策披露。
- **依赖变动快**：browser-use 等发布频繁 → 钉版本、契约测试、升级走评审。
